# 최종 검수 사전 점검

2026-11-04 · G-M7-01 제3자 실행 대기

- 검수본과 출처 대장의 해시가 M6 기록과 일치했다. 통합 데이터 해시는 M6 기록과 별도 환경 자체 재실행 기록 모두와 일치했다.
- 표·그림 21개 보관본의 해시를 자체 재실행 대조 기록과 비교했다. 본문의 로컬 링크 30개와 그림 3개를 확인했다.

- 원자료·중간자료·지역 참조자료·분석 산출물 디렉터리에서 Git이 추적하는 것은 빈 폴더 유지 파일뿐이다. 배포 범위는 자료별 이용조건과 승인 범위를 확인한 뒤 확정한다.
