## 의사결정 관문

- **M1 → M2:** 공식 파일의 범위와 컬럼 구조 확인. 파일 확보만으로 검증 완료 판정하지 않는다.
- **M2 → M3:** 매핑 누락·상하위 중복 없음, 핵심 변수 분모 유효, 선관위 공식 수치 대조 완료.
- **M4 → M5:** 모형별 n과 변수 정의가 기록되어 있고 실패한 가설도 포함해 결과 공개.
- **M6 → M7:** 모든 표·그림이 저장된 분석 코드로 재현된다.

## 작업 우선순위

1. 선관위 시군구 선거인수/투표자수 중복 집계 없이 추출
2. 2025-05 주민등록 연령별 인구의 기준(포함집단) 고정
3. 세종·제주 및 일반구 통합 지역코드 매핑
4. 재정자립도·순이동률의 단위 비교 가능성 확인
5. 코딩·검증 및 첫 실증 결과 확인

이 문서의 일정은 연구 작업 목표이며 완료 여부는 실제 파일과 검증 결과로만 판단한다.
