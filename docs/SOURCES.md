- 원자료 제공·변경 이력과 재배포 라이선스

## 데이터 조립 단계

공식 사이트의 파일 컬럼 구조는 내려받은 후 확인한다. **본 코드의 표준 CSV는 원본 파일과 동일한 컬럼일 것이라고 가정하지 않는다.** 데이터별 스테이징 과정에서 [CODEBOOK](CODEBOOK.md)의 열 이름으로 변환한다.

1. `data/raw/`에 원본 보존 (Git 비추적).
2. `data/interim/`에 `election.csv`, `population.csv`, `fiscal.csv`, `migration.csv` 생성.
3. `data/reference/region_crosswalk.csv`에 데이터셋별 원본 코드 ↔ 연구 단위 코드 매칭.
4. `make build`에서 공식 전국·시도 합계를 직접 대조하고 지역별 집계 기준 차이를 기록.
5. 검증된 결과에 한해 `make analyze` 수행.

**원자료의 비율을 합산하거나, 명칭이 비슷하다는 이유만으로 지역을 자동 매칭하지 않는다.**
